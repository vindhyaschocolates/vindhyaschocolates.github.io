# Vindhya’s Homemade Chocolates

A responsive, 3D-styled static website for Vindhya’s Homemade Chocolates, Basti, Uttar Pradesh.

**Live site:** https://vindhyaschocolates.github.io/

## Highlights

- Dark-chocolate and gold theme with a 3D parallax hero, tilt cards and a spinning 3D collection carousel
- Full menu with prices from the latest catalogue (Single Piece, Lollipops, Boxes, Kunafa Bonbons, Special, Designer, Festive)
- Built-in order builder: tap + on any item, review the basket, and send the order to WhatsApp with one tap
- Gifting section, flavour range, photo gallery with lightbox, QR codes and a downloadable PDF catalogue

## Structure

- `index.html`, `styles.css`, `script.js` – the site (no build step, no dependencies)
- `assets/img/` – optimised photos, cut-outs and scenes (WebP)
- `assets/fonts/` – self-hosted Playfair Display, Great Vibes and Poppins
- `assets/Vindhyas_Catalog.pdf` – the WhatsApp product catalogue

## Local preview

    python -m http.server 8000

Then visit http://localhost:8000.
